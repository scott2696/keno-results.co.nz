Number frequency

How often each number has appeared across the draws we hold. This describes what has happened. It does not predict what will happen.

Read this first

Each Keno draw is independent. Nothing that happened in previous draws changes the chance of any number appearing in the next one — a number drawn ten times in a row is exactly as likely to appear next draw as one that has not appeared at all.

Over a long enough run every number converges toward the same frequency. Short-run differences below are ordinary randomness, not a signal. That is why this page lists numbers in order and shows no ranking, no "hot" or "cold" labels, and no suggestion that any number is due.
