Four draws a day, every day

Across the draws in our archive, Keno has drawn four times daily at consistent times — including weekends and through public holidays. There is no day of the week with more or fewer draws.

  • 10:01amMorning draw
  • 1:01pmMidday draw
  • 3:01pmAfternoon draw
  • 6:01pmEvening draw

All times New Zealand local — NZST or NZDT depending on the season. Our timestamps follow the same clock, so times shown on this site never need converting.

Observed, not official

These times are what we have consistently recorded, not a schedule published to us. Lotto NZ set the draw calendar and can change it. If they do, this page will drift out of date before they tell us — the latest draw timestamp is always the authoritative answer to "when was the last one".

When this site updates

We read the results feed shortly after each draw and republish. In practice a new result appears here within a few minutes of the draw, and every set of numbers carries the exact time we retrieved it, so you can always see how current the page is.

If a draw is late or the feed is unreachable, we keep showing the last confirmed result rather than guessing or blanking the page. A result on this site has always come from the operator.

That frequency is worth keeping in mind. Keno's odds are fixed per draw, so playing four draws a day does not improve them — it simply multiplies how often you are exposed to the same fixed house edge. If you set a limit, set it per day rather than per draw.

Why there is no promotions calendar here

Operator sites often run a calendar of promotions and bonus draws. We are not the operator — we do not run promotions, sell tickets, or take stakes — so there is nothing for us to list, and inventing one would be misleading. For current promotions, go to Lotto NZ directly.

What we can tell you about is the multiplier, which is attached to every draw and published with the result.
